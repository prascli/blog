# Testing

## What runs where

| Layer | Tool | Scope |
| --- | --- | --- |
| Type and template check | `astro check` (part of `pnpm build`) | every `.astro` and `.ts` file |
| Lint | ESLint + `eslint-plugin-astro` | source, scripts |
| Format | Prettier | whole repository |
| Artifact guards | `scripts/postbuild.mjs` | required build outputs, canonical + JSON-LD on home, per-post page and OG image |
| Browser tests | Playwright (desktop 1280×900, mobile 390×844) | routes, metadata, links, behaviour, accessibility |
| Accessibility | `@axe-core/playwright` with WCAG 2.0/2.1/2.2 A+AA tags | 10 routes, both themes audited manually |
| Performance | Lighthouse CLI | 8 routes, hard thresholds at 95 |
| Production | `scripts/verify-production.mjs` | the live domain after every deploy |

```bash
pnpm build        # type check, build, index, artifact guards
pnpm test         # Playwright, against the production build
pnpm test:a11y    # accessibility subset
pnpm lighthouse   # budgets + .cache/lighthouse/*.json
node scripts/verify-production.mjs https://blog.qansa.web.id
```

## Suites

`tests/routes.spec.ts` — every page returns 200 with its heading; articles render
a body and their diagram; unknown paths return 404; category pages list their
articles; legacy `/posts/<slug>.html` serves a canonical stub.

`tests/seo.spec.ts` — title, description, canonical, OG, Twitter, RSS
autodiscovery; per-article `article:*` metadata; JSON-LD parsed and asserted
(Person, WebSite, BlogPosting with author/publisher/articleSection/keywords/
mainEntityOfPage, and BreadcrumbList with the article URL); single `h1`; robots,
sitemap, RSS content; `_redirects` contents; `/og.png` content type.

`tests/behavior.spec.ts` — reading time, progress bar, table of contents, copy
button on code blocks, previous/next link, theme toggle that persists across a
reload, Pagefind search returning an article for body text, and the mobile menu
opening and closing.

`tests/links.spec.ts` — crawls every internal link from seven entry points and
fails on any non-2xx; asserts header navigation on every page; checks
`target="_blank"` links for `noopener`; resolves the external links on the author
page.

`tests/a11y.spec.ts` — axe on ten routes, failing on critical or serious
violations, plus a keyboard test that the first Tab lands on the skip link.

`astro preview`).

| Check | Result |
| --- | --- |

| `pnpm format:check` | all files match |
| `pnpm build` | 19 pages, 2 posts, 5 redirects, dist 2.3 MB |
| `astro check` | 0 errors, 0 warnings, 0 hints (72 files) |
| `pnpm test` | 86 tests, 85 passed, 1 skipped (desktop-only guard), 0 failed |
| axe (light theme) | 0 serious/critical violations on 9 routes |
| axe (dark theme) | 0 serious/critical violations on 9 routes |
| Lighthouse desktop, 8 routes | performance 100, accessibility 100, best practices 100, SEO 100 on every route |
| Lighthouse mobile, home | performance 100, accessibility 100, best practices 100, SEO 100; LCP 0.8 s, CLS 0.001, TBT 0 ms |
| Lighthouse mobile, article | performance 100, accessibility 100, best practices 100, SEO 100; LCP 1.1 s, CLS 0, TBT 0 ms |

Issues found and fixed during the run, kept here because they are easy to
reintroduce:

- Duplicate `og:type` (layout plus article override) — now a single value driven
  by an `ogType` prop.
- Missing `favicon.ico` caused a console 404 and a best-practices failure — the
  ICO is generated by `scripts/make-favicons.mjs` and committed.
- Shiki's `min-light`/`github-dark` comment tokens fell below 4.5:1 — the light
  theme was replaced and dark comments are lifted to the muted foreground colour.
- Tag chips and the footer licence line used a 80%-opacity muted text at 12 px,
  which axe scored at 3.8:1 — both now use the full muted colour.
- Heading anchor links were an empty `<a href="#…">` for screen readers — they
  now carry `aria-label="Link to section: …"`.
- The mobile theme toggle lives inside the collapsed menu, so the test opens the
  menu first instead of assuming the button is clickable.
- Playwright's readiness probe now targets `127.0.0.1` explicitly; on a runner
  where `localhost` resolves to `::1` the preview server was unreachable and the
  suite timed out.
- Header navigation links were 20px tall and the search icon 16px, under the
  WCAG 2.2 AA 24×24 target minimum; both now carry padding and a minimum size
  (28px and 32px measured).
- The article measure started at 92 characters per line. Body text is now 17px
  with a 43rem column, which measures 81 characters per line at 1280px.

`astro preview` allows one instance at a time. When a preview is already running
(for a manual check or a Lighthouse run), point the suite at it instead of
starting a second one:

```bash
PLAYWRIGHT_BASE_URL=http://127.0.0.1:4321 pnpm test
```

## Performance notes

- Fonts are fetched once at build time and emitted as local `woff2` files with
  `font-display: swap` and Arial/Times fallback metrics, so there is no
  third-party request and no layout shift on font swap.
- Total JS for a content page is the Astro view-transition client plus the
  article script (progress bar, copy buttons, lightbox); search ships Pagefind
  only on `/search/`.
- Images: one SVG diagram per article, dimensioned to reserve space.
- `dist` is 2.3 MB including Pagefind's index fragments, both OG images per post
  and the fonts.

## Adding a test

Put it in `tests/` and import from `@playwright/test`. Tests run against the
built site, so anything that depends on content must be generated first
(`pnpm build`). Prefer asserting on structure and metadata over pixel snapshots.
